§C. HASH DO INVENTÁRIO (consulta de uma linha, sem GROUP BY)
-----------------------------------------------------------------------
with known(name) as (
  values ('documents_read'),('documents_insert'),('documents_update'),('documents_delete'),
         ('branding_read'),('branding_insert'),('branding_update'),('branding_delete'),
         ('caepi_base_all'),('caepi_base_platform_all')
), pol as (
  select
    p.policyname,
    p.cmd,
    array_to_string(p.roles::text[], ',')               as roles,
    coalesce(nullif(btrim(p.qual), ''), '<null>')       as using_expr,
    coalesce(nullif(btrim(p.with_check), ''), '<null>') as check_expr
  from pg_policies p
  where p.schemaname = 'storage'
    and p.tablename  = 'objects'
    and p.policyname not in (select name from known)
), agg as (
  select coalesce(string_agg(
           format(E'\n  - %s | cmd=%s | roles=%s | using=%s | check=%s',
                  policyname, cmd, roles, using_expr, check_expr),
           '' order by policyname), '') as inventory
  from pol
)
select
  inventory                        as inventario_completo,
  md5(inventory)                   as ack_hash,
  md5('')                          as hash_da_string_vazia,
  (inventory = '')                 as conjunto_vazio
from agg;

O hash é calculado exatamente como a migration: concatenação das linhas
formatadas, em ordem de policyname, sem separador extra. Conjunto vazio
=> ack_hash = d41d8cd98f00b204e9800998ecf8427e (reconhecimento explícito
de "não há nada a reconhecer" também é obrigatório).

-- =====================================================================
-- Entrega 1 — Escopo de leitura de public.documents
-- Versão: 20261101100100 (única)  |  Ordem de aplicação: 1 de 4 pendentes
-- =====================================================================
--
-- ⚠️  NÃO EXECUTADO PELO AGENTE. Aplicar manualmente (SQL Editor) ou pelo
--     script mestre supabase/scripts/entrega1_apply_all_transactional.sql.
--
-- ESTE ARQUIVO NÃO TEM begin;/commit; PRÓPRIOS. Ele é um corpo de statements.
-- A atomicidade vem de fora: o SQL Editor envolve o script inteiro em uma
-- transação, e o Supabase CLI envolve cada migration em uma transação.
--
-- Decisão de acesso (vale para a tabela e é espelhada no Storage):
--   * Administrador da empresa (profiles.role = 'admin'): todos os
--     documentos da própria empresa.
--   * Colaborador: documentos individuais DELE + materiais GERAIS
--     publicados (scope <> 'colaborador' e visible_to_collaborator = true).
--   * Documento individual de outra pessoa: inacessível, mesmo com
--     visible_to_collaborator = true.
--   * Usuário sem contexto de empresa definido (0 ou 2+ vínculos ativos):
--     nega tudo. Decisão de produto — a seleção de empresa é outra entrega.
--
-- Não existe papel 'super' em public.profiles:
--   profiles_role_check = CHECK (role = ANY (ARRAY['admin','collaborator']))
--
-- ESTADO REAL CONFERIDO (pg_policies em public.documents):
--   documents_all        | ALL    | public        | false | false -> deny
--   legacy_all_disabled  | ALL    | authenticated | false | false -> deny
--   tenant_read          | SELECT | authenticated | is_current_company_ref(company_ref)
--   tenant_write         | ALL    | authenticated | is_current_company_ref(company_ref)
--                                                    AND current_company_role() = 'admin'
--
-- CORREÇÃO DO INVENTÁRIO (revisão externa, item 2):
--   A versão anterior abortava com QUALQUER policy SELECT/ALL cujo `qual`
--   não fosse literalmente false — inclusive `tenant_write`, que é ALL de
--   administrador e é legítima. Agora:
--     * `tenant_write` é verificada pela FORMA (comando, papéis, expressão
--       de admin e ausência de 'super'); se mudar, aborta.
--     * policies RESTRITIVAS nunca são tratadas como concessão de leitura
--       (restrictive só estreita; não soma por OR).
--     * policies desconhecidas só abortam quando são PERMISSIVAS e de
--       leitura (SELECT/ALL) com `qual` que não seja literalmente false.
--     * policies desconhecidas de escrita (INSERT/UPDATE) não ampliam
--       leitura; ficam registradas como aviso, não como bloqueio.
--
-- Recuperação: supabase/recovery/20261101100100_entrega1_documents_scope_policy_recovery.sql
--              (fail-closed: NÃO restaura leitura ampla)
-- =====================================================================

-- ---------------------------------------------------------------------
-- 1) Inventário com reconhecimento da autorização administrativa
-- ---------------------------------------------------------------------
do $inventory$
declare
  pol record;
  v_problems text[] := array[]::text[];
begin
  for pol in
    select policyname, permissive, cmd, roles::text[] as roles, qual, with_check
    from pg_policies
    where schemaname = 'public' and tablename = 'documents'
    order by policyname
  loop
    -- Substituída logo abaixo.
    if pol.policyname = 'tenant_read' then
      continue;
    end if;

    -- Autorização administrativa necessária: precisa existir e ter esta forma.
    if pol.policyname = 'tenant_write' then
      if pol.permissive <> 'PERMISSIVE'
         or pol.cmd <> 'ALL'
         or pol.roles is distinct from array['authenticated']::text[]
         or coalesce(pol.qual, '') !~* 'is_current_company_ref'
         or coalesce(pol.qual, '') !~* 'current_company_role\s*\(\s*\)\s*=\s*''admin'''
         or coalesce(pol.with_check, '') !~* 'current_company_role\s*\(\s*\)\s*=\s*''admin'''
         or coalesce(pol.qual, '') ~* '''super'''
         or coalesce(pol.with_check, '') ~* '''super'''
         or btrim(coalesce(pol.qual, '')) in ('true', '(true)')
         or btrim(coalesce(pol.with_check, '')) in ('true', '(true)') then
        v_problems := v_problems || format(
          'tenant_write mudou de forma (cmd=%s, papéis=%s, using=%s, check=%s). A autorização administrativa precisa ser revista manualmente.',
          pol.cmd,
          array_to_string(pol.roles, ','),
          coalesce(pol.qual, '<null>'),
          coalesce(pol.with_check, '<null>')
        );
      end if;
      continue;
    end if;

    -- Deny placeholders conhecidos: exigem false/false.
    if pol.policyname in ('documents_all', 'legacy_all_disabled') then
      if pol.cmd <> 'ALL'
         or btrim(coalesce(pol.qual, '')) not in ('false', '(false)')
         or btrim(coalesce(pol.with_check, '')) not in ('false', '(false)') then
        v_problems := v_problems || format(
          '%s deveria negar tudo (false/false) mas está como using=%s check=%s',
          pol.policyname,
          coalesce(pol.qual, '<null>'),
          coalesce(pol.with_check, '<null>')
        );
      end if;
      continue;
    end if;

    -- Política desconhecida: só amplia leitura se for PERMISSIVA e de leitura.
    if pol.permissive = 'PERMISSIVE' and pol.cmd in ('SELECT', 'ALL') then
      if btrim(coalesce(pol.qual, 'true')) not in ('false', '(false)') then
        v_problems := v_problems || format(
          '%s concede leitura em documents (cmd %s, papéis %s) com expressão %s',
          pol.policyname,
          pol.cmd,
          array_to_string(pol.roles, ','),
          coalesce(pol.qual, '<null>')
        );
      end if;
    elsif pol.permissive = 'PERMISSIVE' then
      raise notice 'Aviso: policy % de escrita (cmd %) em documents não reconhecida. Não amplia leitura; as referências de arquivo são validadas por gatilho.', pol.policyname, pol.cmd;
    end if;
  end loop;

  if array_length(v_problems, 1) is not null then
    raise exception
      E'Migração interrompida. NENHUMA policy foi alterada.\nPolicies de leitura extra em public.documents:\n  - %\nRevise antes de continuar.',
      array_to_string(v_problems, E'\n  - ');
  end if;
end
$inventory$;

-- ---------------------------------------------------------------------
-- 2) Substitui a leitura
-- ---------------------------------------------------------------------
drop policy if exists tenant_read on public.documents;

create policy tenant_read on public.documents
  for select to authenticated
  using (
    public.is_current_company_ref(company_ref)
    and (
      public.current_company_role() = 'admin'
      -- Documento individual do próprio colaborador
      or (
        scope = 'colaborador'
        and collaborator_id is not null
        and public.current_collaborator_ref() is not null
        and collaborator_id = public.current_collaborator_ref()
      )
      -- Material geral explicitamente publicado para colaboradores
      or (
        coalesce(scope, 'empresa') <> 'colaborador'
        and visible_to_collaborator is true
      )
    )
  );

-- ---------------------------------------------------------------------
-- 3) Conferência estrutural (mesmas regras do inventário)
-- ---------------------------------------------------------------------
do $check$
declare
  v_problem text[] := array[]::text[];
  pol record;
begin
  select * into pol
  from pg_policies
  where schemaname = 'public' and tablename = 'documents' and policyname = 'tenant_read';

  if pol.policyname is null then
    v_problem := v_problem || 'tenant_read não existe';
  else
    if pol.cmd <> 'SELECT' then
      v_problem := v_problem || format('tenant_read com cmd %s', pol.cmd);
    end if;
    if pol.roles::text[] is distinct from array['authenticated']::text[] then
      v_problem := v_problem || format('tenant_read com papéis %s', array_to_string(pol.roles::text[], ','));
    end if;
    if coalesce(pol.qual, '') !~* 'current_company_role' then
      v_problem := v_problem || 'tenant_read sem checagem de papel';
    end if;
    if coalesce(pol.qual, '') !~* 'collaborator_id' then
      v_problem := v_problem || 'tenant_read sem checagem de colaborador';
    end if;
    if coalesce(pol.qual, '') ~* '''super''' then
      v_problem := v_problem || 'tenant_read usa o papel inexistente ''super''';
    end if;
  end if;

  -- tenant_write precisa continuar existindo e autorizando apenas admin.
  select * into pol
  from pg_policies
  where schemaname = 'public' and tablename = 'documents' and policyname = 'tenant_write';

  if pol.policyname is null then
    v_problem := v_problem || 'tenant_write desapareceu (administrador perderia a escrita)';
  elsif pol.cmd <> 'ALL'
        or coalesce(pol.qual, '') !~* 'current_company_role\s*\(\s*\)\s*=\s*''admin'''
        or coalesce(pol.qual, '') ~* '''super''' then
    v_problem := v_problem || 'tenant_write não autoriza apenas admin da própria empresa';
  end if;

  for pol in
    select policyname, permissive, cmd, qual, with_check
    from pg_policies
    where schemaname = 'public' and tablename = 'documents'
      and policyname not in ('tenant_read', 'tenant_write')
  loop
    if pol.policyname in ('documents_all', 'legacy_all_disabled') then
      if btrim(coalesce(pol.qual, '')) not in ('false', '(false)')
         or btrim(coalesce(pol.with_check, '')) not in ('false', '(false)') then
        v_problem := v_problem || format('%s deixou de negar tudo', pol.policyname);
      end if;
    elsif pol.permissive = 'PERMISSIVE' and pol.cmd in ('SELECT', 'ALL') then
      if btrim(coalesce(pol.qual, 'true')) not in ('false', '(false)') then
        v_problem := v_problem || format('policy extra %s concedendo leitura', pol.policyname);
      end if;

-- 4) Nova versão: validação do original e cálculo da revisão
-- ---------------------------------------------------------------------
create or replace function public.medical_certificates_before_insert()
returns trigger
language plpgsql
security definer
set search_path to ''
as $$
declare
  parent public.medical_certificates%rowtype;
begin
  if new.replaces_id is null then
    new.revision := 1;
    return new;
  end if;

  if new.replaces_id = new.id then
    raise exception 'Um atestado não pode substituir a si mesmo.'
      using errcode = 'check_violation';
  end if;

  perform pg_advisory_xact_lock(hashtext('medical_certificates:revision:' || new.replaces_id::text));

  select * into parent
  from public.medical_certificates m
  where m.id = new.replaces_id;

  if parent.id is null then
    raise exception 'replaces_id não corresponde a nenhum atestado existente.'
      using errcode = 'check_violation';
  end if;

  if parent.company_id is distinct from new.company_id
     or parent.collaborator_ref is distinct from new.collaborator_ref then
    raise exception 'A correção precisa pertencer à mesma empresa e ao mesmo colaborador do atestado original.'
      using errcode = 'check_violation';
  end if;

  if exists (
    select 1 from public.medical_certificates c where c.replaces_id = parent.id
  ) then
    raise exception 'Este atestado já foi substituído por outra versão. Corrija a versão vigente.'
      using errcode = 'check_violation';
  end if;

  if parent.storage_path is not null and parent.storage_path = new.storage_path then
    raise exception 'A nova versão precisa apontar para um arquivo novo (o original é preservado).'
      using errcode = 'check_violation';
  end if;

  new.revision := coalesce(parent.revision, 1) + 1;
  return new;
end
$$;

-- ---------------------------------------------------------------------
-- 1) Inventário OBRIGATÓRIO com reconhecimento explícito
-- ---------------------------------------------------------------------
-- * Toda policy de storage.objects fora da lista conhecida é listada e o md5
--   do conjunto é exigido em `app.storage_policy_ack`. Sem o hash, aborta
--   ANTES de qualquer drop — inclusive quando o conjunto está VAZIO
--   (hash de string vazia d41d8cd98f00b204e9800998ecf8427e).
-- * Bloqueios duros, apenas para policies PERMISSIVAS (restritiva só estreita
--   e não pode conceder nada por OR):
--     (i)   desconhecida que cita documents|branding|caepi-base;
--     (ii)  desconhecida sem filtro de bucket_id;
--     (iii) desconhecida com expressão literalmente null/true.
-- * Não existe verificação automática de "expressão permissiva" (ex.:
--   bucket_id <> 'avatars'). A cobertura é revisão humana do inventário.
do $inventory$
declare
  pol record;
  v_known text[] := array[
    'documents_read','documents_insert','documents_update','documents_delete',
    'branding_read','branding_insert','branding_update','branding_delete',
    'caepi_base_all','caepi_base_platform_all'
  ];
  v_others text[] := array[]::text[];
  v_issues text[] := array[]::text[];
  v_hash text;
  v_ack text := coalesce(current_setting('app.storage_policy_ack', true), '');
  v_qual_free boolean;
  v_check_free boolean;
begin
  for pol in
    select p.policyname, p.permissive, p.cmd, p.roles::text[] as roles, p.qual, p.with_check
    from pg_policies p
    where p.schemaname = 'storage' and p.tablename = 'objects'
    order by p.policyname
  loop
    if pol.policyname = any (v_known) then
      continue;
    end if;

    v_others := v_others || format(
      E'\n  - %s | cmd=%s | roles=%s | using=%s | check=%s',
      pol.policyname,
      pol.cmd,
      array_to_string(pol.roles, ','),
      coalesce(nullif(btrim(pol.qual), ''), '<null>'),
      coalesce(nullif(btrim(pol.with_check), ''), '<null>')
    );

    if pol.permissive <> 'PERMISSIVE' then
      continue;  -- restritiva não amplia acesso
    end if;

    if coalesce(pol.qual, '') ~* '(documents|branding|caepi-base)'
       or coalesce(pol.with_check, '') ~* '(documents|branding|caepi-base)' then
      v_issues := v_issues || format('%s cita bucket isolado e não é conhecida (cmd %s)', pol.policyname, pol.cmd);
      continue;
    end if;

    if coalesce(pol.qual, '') !~* 'bucket_id'
       and coalesce(pol.with_check, '') !~* 'bucket_id' then
      v_issues := v_issues || format('%s não restringe por bucket_id (cmd %s)', pol.policyname, pol.cmd);
      continue;
    end if;

    v_qual_free := pol.qual is null or btrim(pol.qual) in ('true', '(true)');
    v_check_free := pol.with_check is null or btrim(pol.with_check) in ('true', '(true)');

    if (pol.cmd in ('SELECT', 'DELETE') and v_qual_free)
       or (pol.cmd = 'INSERT' and v_check_free)
       or (pol.cmd = 'UPDATE' and v_qual_free and v_check_free)
       or (pol.cmd = 'ALL' and (v_qual_free or v_check_free)) then
      v_issues := v_issues || format('%s tem expressão literalmente irrestrita (cmd %s)', pol.policyname, pol.cmd);
    end if;
  end loop;

  v_hash := md5(coalesce(array_to_string(v_others, ''), ''));

  if array_length(v_issues, 1) is not null then
    raise exception
      E'Migração interrompida. NENHUMA permissão foi alterada.\nProblemas que exigem decisão humana:\n  - %\nInventário de storage.objects fora da lista conhecida:%',
      array_to_string(v_issues, E'\n  - '),
      coalesce(array_to_string(v_others, ''), E'\n  (vazio)');
  end if;

  if v_ack <> v_hash then
    raise exception
      E'Revisão explícita do inventário pendente. NENHUMA permissão foi alterada.\nPolicies de storage.objects fora da lista conhecida:%\n\nHash do conjunto: %\n\nRevise cada linha acima e reexecute com:\n  select set_config(''app.storage_policy_ack'', ''%'', true);',
      coalesce(array_to_string(v_others, ''), E'\n  (nenhuma)'),
      v_hash,
      v_hash;
  end if;

  raise notice 'Inventário reconhecido (hash %).', v_hash;
end

create or replace function public.storage_path_in_current_company(p_name text)
returns boolean
language sql
stable
security definer
set search_path to ''
as $$
  select
    coalesce(p_name, '') <> ''
    and p_name !~* '^(data:|https?:|blob:)'
    and position('..' in p_name) = 0
    and left(p_name, 1) <> '/'
    and public.current_company_subdomain() is not null
    and lower(split_part(p_name, '/', 1)) = public.current_company_subdomain()
$$;

create or replace function public.storage_path_is_own_certificate_folder(p_name text)
returns boolean
language sql
stable
security definer
set search_path to ''
as $$
  select
    public.storage_path_in_current_company(p_name)
    and public.current_collaborator_ref() is not null
    and split_part(p_name, '/', 2) = 'atestados'
    and split_part(p_name, '/', 3) = public.current_collaborator_ref()
    and array_length(string_to_array(p_name, '/'), 1) >= 4
$$;

-- O objeto existe MESMO no bucket informado? (bucket + caminho)

-- O caminho pertence a um atestado da empresa do chamador?
create or replace function public.storage_path_is_medical_certificate(p_bucket text, p_name text)
returns boolean
language sql

security definer
set search_path to ''
as $$
  select
    p_bucket = 'documents'
    and public.current_company_subdomain() is not null

      where m.storage_path = p_name
    )
$$;

-- Escopo do objeto, resolvido por REGISTRO **e** por bucket/caminho reais.
create or replace function public.storage_object_scope(p_bucket text, p_name text)
returns text
language sql
stable
security definer
set search_path to ''
as $$
  with me as (
    select
      public.current_company_id()        as company_id,
      public.current_company_subdomain() as subdomain,
      public.current_collaborator_ref()  as collaborator_ref
  )
  select case
    when me.company_id is null or me.subdomain is null then null
    -- O registro sozinho não autoriza: o objeto precisa existir no bucket
    -- informado e o caminho precisa estar na pasta da empresa atual.
    when not public.storage_object_exists(p_bucket, p_name) then null
    when not public.storage_path_in_current_company(p_name) then null

    -- Branding só existe no bucket branding.
    when p_bucket = 'branding' then
      case
        when exists (
          select 1 from public.company_settings s
          where s.company_id = me.company_id
            and (s.logo_path = p_name or s.letterhead_path = p_name)
        ) then 'branding'
        else null
      end

    when p_bucket = 'documents' then
      case
        -- 1) Atestado médico (precedência máxima)
        when exists (
          select 1 from public.medical_certificates m
          where m.storage_path = p_name
            and (m.company_id = me.company_id or lower(m.company_ref) = me.subdomain)
        ) then
          case
            when me.collaborator_ref is not null
              and exists (
                select 1 from public.medical_certificates m
                where m.storage_path = p_name
                  and (m.company_id = me.company_id or lower(m.company_ref) = me.subdomain)
                  and m.collaborator_ref = me.collaborator_ref
              )
            then 'cert_self'
            else 'cert_other'
          end

        -- 2) Documento individual do próprio colaborador
        when exists (
          select 1 from public.documents d
          where d.storage_path = p_name
            and (d.company_id = me.company_id or lower(d.company_ref) = me.subdomain)
            and d.scope = 'colaborador'
            and me.collaborator_ref is not null
            and d.collaborator_id = me.collaborator_ref
        ) then 'doc_self'

        -- 3) Documento individual de OUTRA pessoa
        when exists (
          select 1 from public.documents d
          where d.storage_path = p_name
            and (d.company_id = me.company_id or lower(d.company_ref) = me.subdomain)
            and d.scope = 'colaborador'
        ) then 'doc_other'

        -- 4) Material geral publicado para colaboradores
        when exists (
          select 1 from public.documents d
          where d.storage_path = p_name
            and (d.company_id = me.company_id or lower(d.company_ref) = me.subdomain)
            and coalesce(d.scope, 'empresa') <> 'colaborador'
            and d.visible_to_collaborator is true
        ) then 'doc_general'

        -- 5) Material interno da empresa (só administração)
        when exists (
          select 1 from public.documents d
          where d.storage_path = p_name
            and (d.company_id = me.company_id or lower(d.company_ref) = me.subdomain)
        ) then 'doc_internal'

        -- 6) Regulamento interno
        when exists (
          select 1 from public.internal_regulations r
          where r.storage_path = p_name
            and lower(r.company_ref) = me.subdomain
        ) then 'regulation'

        else null
      end

    else null
  end
  from me
$$;

-- ---------------------------------------------------------------------
-- 4) Validação de propriedade de referências (usada por gatilhos)
--    Devolve NULL quando está tudo certo, ou o motivo da recusa.
-- ---------------------------------------------------------------------
create or replace function public.storage_reference_problem(
  p_bucket text,
  p_name text,
  p_company_id uuid,
  p_company_ref text,
  p_collaborator_ref text,
  p_kind text
)
returns text
language plpgsql
stable
security definer
set search_path to ''
as $$
declare
  v_subdomain text;
  v_company_id uuid;
  v_expected_bucket text;
  v_parts text[];
begin
  if p_name is null or btrim(p_name) = '' then
    return 'caminho de arquivo vazio';
  end if;

  if p_name ~* '^(data:|https?:|blob:)' then
    return 'referência não é um caminho de Storage';
  end if;

  if left(p_name, 1) = '/' or p_name ~ '(^|/)\.\.(/|$)' then
    return 'caminho de arquivo inválido';
  end if;

  v_expected_bucket := case when p_kind = 'branding' then 'branding' else 'documents' end;
  if p_bucket is distinct from v_expected_bucket then
    return format('bucket %s incompatível com a referência %s', coalesce(p_bucket, '<null>'), p_kind);
  end if;

  -- Resolve a empresa do REGISTRO e confere company_id x company_ref.
  if p_company_id is not null then
    select c.id, lower(c.subdomain)
      into v_company_id, v_subdomain
    from public.companies c
    where c.id = p_company_id;

    if v_company_id is null then
      return 'empresa do registro não existe';
    end if;

    if p_company_ref is not null and lower(btrim(p_company_ref)) <> v_subdomain then
      return 'company_ref não corresponde ao company_id do registro';
    end if;
  elsif p_company_ref is not null and btrim(p_company_ref) <> '' then
    select c.id, lower(c.subdomain)
      into v_company_id, v_subdomain
    from public.companies c
    where lower(c.subdomain) = lower(btrim(p_company_ref));

    if v_company_id is null then
      return 'company_ref do registro não corresponde a nenhuma empresa';
    end if;
  else
    return 'registro sem empresa identificada';
  end if;

  v_parts := string_to_array(p_name, '/');

  -- O caminho é a prova de empresa; o registro não é.
  if lower(coalesce(v_parts[1], '')) <> v_subdomain then
    return 'arquivo não pertence à pasta da empresa do registro';
  end if;

  -- Existência real do objeto no bucket esperado.
  if not exists (
    select 1 from storage.objects o
    where o.bucket_id = v_expected_bucket and o.name = p_name
  ) then
    return format('arquivo não existe no bucket %s', v_expected_bucket);
  end if;

  if p_kind = 'certificate' then
    if coalesce(btrim(p_collaborator_ref), '') = '' then
      return 'atestado sem colaborador identificado';
    end if;
    if coalesce(v_parts[2], '') <> 'atestados' then
      return 'atestado precisa estar em <empresa>/atestados/<colaborador>/';
    end if;
    if coalesce(v_parts[3], '') <> p_collaborator_ref then
      return 'atestado aponta para a pasta de outro colaborador';
    end if;
    if array_length(v_parts, 1) < 4 then
      return 'caminho de atestado incompleto';
    end if;
    if exists (select 1 from public.documents d where d.storage_path = p_name)
       or exists (select 1 from public.internal_regulations r where r.storage_path = p_name) then
      return 'caminho já usado por documento ou regulamento';
    end if;

  elsif p_kind in ('document', 'regulation') then
    if exists (select 1 from public.medical_certificates m where m.storage_path = p_name) then
      return 'caminho já pertence a um atestado médico';
    end if;

  elsif p_kind = 'branding' then
    if coalesce(v_parts[2], '') not in ('logo', 'letterhead') then
      return 'branding precisa estar em <empresa>/logo/ ou <empresa>/letterhead/';
    end if;

  else
    return format('tipo de referência desconhecido: %s', coalesce(p_kind, '<null>'));
  end if;

  return null;
end
$$;

create or replace function public.documents_validate_storage_reference()
returns trigger
language plpgsql
security definer
set search_path to ''
as $$
declare
  v_problem text;
begin
  if new.storage_path is null or btrim(new.storage_path) = '' then
    return new;
  end if;

  v_problem := public.storage_reference_problem(
    'documents', new.storage_path, new.company_id, new.company_ref, null, 'document'
  );

  if v_problem is not null then
    raise exception 'Referência de arquivo recusada em documents: %', v_problem
      using errcode = 'check_violation';
  end if;

  return new;
end
$$;

create or replace function public.storage_can_read(p_bucket text, p_name text)
returns boolean
language sql
stable
security definer
set search_path to ''
as $$
  select case
    when p_bucket = 'documents' then (
      public.current_company_subdomain() is not null
      and public.storage_object_exists(p_bucket, p_name)
      and case
        when public.current_company_role() = 'admin' then
          public.storage_object_scope(p_bucket, p_name) is not null
          or public.storage_path_in_current_company(p_name)
        else
          public.storage_object_scope(p_bucket, p_name) in ('cert_self', 'doc_self', 'doc_general', 'regulation')
          -- Permite confirmar o upload na PRÓPRIA pasta de atestados antes de
          -- o registro existir (fluxo: upload -> confirmação -> INSERT).
          or public.storage_path_is_own_certificate_folder(p_name)
      end
    )
    when p_bucket = 'branding' then (
      public.current_company_subdomain() is not null
      and public.storage_object_exists(p_bucket, p_name)
      and (
        public.storage_object_scope(p_bucket, p_name) = 'branding'
        or (
          public.storage_object_scope(p_bucket, p_name) is null
          and public.storage_path_in_current_company(p_name)
        )
      )
    )
    when p_bucket = 'caepi-base' then public.is_platform_admin()
    else false
  end
$$;

create or replace function public.storage_can_insert(p_bucket text, p_name text)
returns boolean
language sql
stable
security definer
set search_path to ''
as $$
  select case
    when p_bucket = 'documents' then (
      public.storage_path_in_current_company(p_name)
      and public.current_company_role() is not null
      and (
        public.current_company_role() = 'admin'
        or public.storage_path_is_own_certificate_folder(p_name)
      )
      -- Nunca gravar por cima de um caminho já registrado como atestado.
      and not exists (
        select 1 from public.medical_certificates m where m.storage_path = p_name
      )
    )
    when p_bucket = 'branding' then (
      public.storage_path_in_current_company(p_name)
      and public.current_company_role() = 'admin'
    )
    when p_bucket = 'caepi-base' then public.is_platform_admin()
    else false
  end
$$;

-- ---------------------------------------------------------------------
-- 8) Conferência final por REGRA e PAPEL
-- ---------------------------------------------------------------------
do $check$
declare
  r record;
  v_problem text[] := array[]::text[];
  v_expected text[] := array[
    'documents_read','documents_insert','documents_update','documents_delete',
    'branding_read','branding_insert','branding_update','branding_delete',
    'caepi_base_platform_all'
  ];
begin
  for r in
    select e.policyname as expected_name, e.cmd as expected_cmd,
           p.policyname, p.cmd, p.roles::text[] as roles
    from (values
      ('documents_read', 'SELECT'),
      ('documents_insert', 'INSERT'),
      ('documents_update', 'UPDATE'),
      ('documents_delete', 'DELETE'),
      ('branding_read', 'SELECT'),
      ('branding_insert', 'INSERT'),
      ('branding_update', 'UPDATE'),
      ('branding_delete', 'DELETE'),
      ('caepi_base_platform_all', 'ALL')
    ) as e(policyname, cmd)
    left join pg_policies p
      on p.schemaname = 'storage'
     and p.tablename = 'objects'
     and p.policyname = e.policyname
  loop
    if r.policyname is null then
      v_problem := v_problem || format('faltando policy %s', r.expected_name);
      continue;
    end if;

    if r.cmd is distinct from r.expected_cmd then
      v_problem := v_problem || format('%s com cmd %s (esperado %s)', r.expected_name, r.cmd, r.expected_cmd);
    end if;

      v_problem := v_problem || format('%s com papéis %s (esperado authenticated)', r.expected_name, array_to_string(r.roles, ','));
    end if;
  end loop;

  for r in
    select policyname, permissive, qual, with_check
    from pg_policies
    where schemaname = 'storage' and tablename = 'objects'
  loop
    if r.policyname = any (v_expected) then
      continue;
    end if;

    if r.permissive <> 'PERMISSIVE' then
      continue;
    end if;

    if coalesce(r.qual, '') ~* '(documents|branding|caepi-base)'
       or coalesce(r.with_check, '') ~* '(documents|branding|caepi-base)' then
      v_problem := v_problem || format('policy extra %s cita bucket isolado', r.policyname);
    elsif coalesce(r.qual, '') !~* 'bucket_id'
       and coalesce(r.with_check, '') !~* 'bucket_id' then
      v_problem := v_problem || format('policy extra %s não restringe por bucket_id', r.policyname);
    end if;
  end loop;

    select 1 from storage.buckets
    where id in ('documents', 'branding', 'caepi-base') and public = true
  ) then
    v_problem := v_problem || 'bucket público remanescente';

    select f.sig
    from (values
      ('public.storage_path_in_current_company(text)'),
      ('public.storage_path_is_own_certificate_folder(text)'),
      ('public.storage_object_exists(text,text)'),
      ('public.storage_path_is_medical_certificate(text,text)'),
      ('public.storage_object_scope(text,text)'),
      ('public.storage_can_read(text,text)'),
      ('public.storage_can_insert(text,text)'),
      ('public.storage_can_update(text,text)'),
      ('public.storage_can_delete(text,text)'),
      ('public.storage_reference_problem(text,text,uuid,text,text,text)')
    ) as f(sig)

    if not exists (
      select 1 from pg_proc p
      where p.oid = to_regprocedure(r.sig)
        and p.prosecdef = true
        and p.proconfig is not null
        and array_to_string(p.proconfig, ',') ~ 'search_path='
    ) then
      v_problem := v_problem || format('%s ausente, sem SECURITY DEFINER ou sem search_path fixo', r.sig);
    end if;

    if has_function_privilege('anon', r.sig, 'EXECUTE') then
      v_problem := v_problem || format('%s executável por anon', r.sig);
    end if;
  end loop;

  -- Helpers de sessão: nenhum EXECUTE herdado de PUBLIC, nenhum grant a anon,
  -- e authenticated preservado. `has_function_privilege('anon', …)` já é
  -- verdadeiro quando o direito vem de PUBLIC, mas a checagem explícita de
  -- PUBLIC evita depender dessa semântica.
  for r in
    select f.sig
    from (values
      ('public.current_collaborator_ref()'),
      ('public.current_company_subdomain()'),
      ('public.current_company_id()'),
      ('public.current_company_role()'),
      ('public.is_current_company_ref(text)'),
      ('public.is_company_member(uuid)'),
      ('public.is_company_admin(uuid)')
    ) as f(sig)
  loop
    if has_function_privilege('anon', r.sig, 'EXECUTE') then
      v_problem := v_problem || format('%s executável por anon (grant direto ou herdado de PUBLIC)', r.sig);
    end if;

    if exists (
      select 1
      from pg_proc p
      cross join lateral aclexplode(coalesce(p.proacl, acldefault('f', p.proowner))) a
      where p.oid = to_regprocedure(r.sig)
        and a.grantee = 0
        and a.privilege_type = 'EXECUTE'
    ) then
      v_problem := v_problem || format('%s ainda concede EXECUTE a PUBLIC', r.sig);
    end if;

    if not has_function_privilege('authenticated', r.sig, 'EXECUTE') then
      v_problem := v_problem || format('%s perdeu EXECUTE para authenticated (chamada legítima quebraria)', r.sig);
    end if;
  end loop;

  -- Gatilhos precisam existir e NÃO podem ser executáveis pelo cliente.
  for r in
    select t.tgname, t.tgrelid::regclass::text as tbl, t.tgfoid::regprocedure::text as fnsig
    from pg_trigger t
    where not t.tgisinternal
      and t.tgname in (
        'documents_validate_storage_reference',
        'medical_certificates_validate_file_reference',
        'internal_regulations_validate_storage_reference',
        'company_settings_validate_branding_reference'
      )
  loop
    if has_function_privilege('anon', r.fnsig, 'EXECUTE')
       or has_function_privilege('authenticated', r.fnsig, 'EXECUTE') then
      v_problem := v_problem || format('função de gatilho %s executável por cliente', r.fnsig);
    end if;
  end loop;

  if not exists (select 1 from pg_trigger where tgname = 'documents_validate_storage_reference' and not tgisinternal) then
    v_problem := v_problem || 'gatilho documents_validate_storage_reference ausente';
  end if;  if not exists (select 1 from pg_trigger where tgname = 'medical_certificates_validate_file_reference' and not tgisinternal) then
    v_problem := v_problem || 'gatilho medical_certificates_validate_file_reference ausente';
  end if;
  if not exists (select 1 from pg_trigger where tgname = 'internal_regulations_validate_storage_reference' and not tgisinternal) then
    v_problem := v_problem || 'gatilho internal_regulations_validate_storage_reference ausente';
  end if;
  if not exists (select 1 from pg_trigger where tgname = 'company_settings_validate_branding_reference' and not tgisinternal) then
    v_problem := v_problem || 'gatilho company_settings_validate_branding_reference ausente';
  end if;

  -- A checagem de existência lê storage.objects, cujo dono é
  -- supabase_storage_admin (RLS habilitada, FORCE desligada). O dono destas
  -- funções precisa de BYPASSRLS; sem isso as policies `to authenticated`
  -- escondem as linhas e tudo seria negado. Verificado no banco atual:
  -- executor `postgres` com rolbypassrls = true.
  if not exists (
    select 1
    from pg_proc p
    join pg_roles r on r.rolname = pg_get_userbyid(p.proowner)
    where p.oid = to_regprocedure('public.storage_reference_problem(text,text,uuid,text,text,text)')
      and r.rolbypassrls
  ) then
    v_problem := v_problem || 'dono das funções de Storage sem BYPASSRLS: a checagem de existência pode negar tudo';
  end if;

  if array_length(v_problem, 1) is not null then
    raise exception 'Conferência final falhou: %', array_to_string(v_problem, ' | ');
  end if;
end
$check$;

-- =====================================================================

-- ⚠️  NÃO EXECUTADO PELO AGENTE. Aplicar manualmente ou pelo script mestre
--     supabase/scripts/entrega1_apply_all_transactional.sql.
--
-- ESTE ARQUIVO NÃO TEM begin;/commit; PRÓPRIOS (a transação vem de fora).
--
-- Duas camadas:
--   * Servidor (implantado): platform-admin / upsert_company responde
--     409 SUBDOMAIN_IMMUTABLE quando o subdomínio muda em edição.
--   * Banco (este arquivo): gatilho bloqueia UPDATE de subdomain.
--
-- `app.allow_subdomain_change` NÃO é autorização. Qualquer sessão define os
-- próprios GUCs, inclusive um usuário comum autenticado. Por isso o gatilho
-- exige DUAS coisas:
--   1) privilégio real: is_platform_admin() (derivado de auth.uid() +
--      platform_admins.status='active'), OU sessão direta do proprietário do
--      banco (current_user in ('postgres','supabase_admin')) — caminho que só
--      existe no console SQL; o PostgREST sempre executa como
--      authenticator -> anon/authenticated/service_role;
--   2) o marcador do procedimento planejado.
--
-- A função é SECURITY INVOKER de propósito: com SECURITY DEFINER,
-- `current_user` passaria a ser o dono (postgres) e o teste de proprietário
-- seria sempre verdadeiro — bypass silencioso. O $check$ falha se alguém
-- tornar a função DEFINER.
--
-- Recuperação: supabase/recovery/20261101100400_entrega1_subdomain_immutability_recovery.sql
--              (rollback exato: remove só o que este arquivo criou)
-- =====================================================================

create or replace function public.companies_block_subdomain_change()
returns trigger
language plpgsql
security invoker
set search_path to ''
as $$
declare
  v_privileged boolean;
  v_marker boolean;
begin
  if new.subdomain is not distinct from old.subdomain then
    return new;
  end if;

  v_privileged := public.is_platform_admin()
                  or current_user in ('postgres', 'supabase_admin');

  if not v_privileged then
    raise exception
      'Somente o super usuário da plataforma pode alterar o subdomínio, e apenas por procedimento planejado.'
      using errcode = 'check_violation';
  end if;

  v_marker := coalesce(current_setting('app.allow_subdomain_change', true), '') = 'true';

  if not v_marker then
    raise exception
      'Subdomínio é imutável por este fluxo. A troca exige procedimento planejado: set local app.allow_subdomain_change = ''true'' na mesma transação, executado pelo proprietário.'
      using errcode = 'check_violation';
  end if;

  return new;
end
$$;

-- ---------------------------------------------------------------------
-- Empresa atual: EXATAMENTE UM vínculo ativo. Com 0 ou 2+ devolve NULL
-- (decisão fail-closed; seleção de empresa é outra entrega).
-- ---------------------------------------------------------------------
CREATE OR REPLACE FUNCTION public.current_company_id()
 RETURNS uuid
 LANGUAGE sql
 STABLE SECURITY DEFINER
 SET search_path TO ''
AS $function$
  with links as (
    select distinct p.company_id
    from public.profiles p
    join public.companies c on c.id = p.company_id
    where p.auth_user_id = auth.uid()
      and p.status = 'active'
      and p.company_id is not null
      and c.status in ('active','trial')
  )
  select case when count(*) = 1 then (array_agg(company_id))[1] else null end from links
$function$;

-- ---------------------------------------------------------------------
-- Subdomínio da empresa atual (company_ref das tabelas).
-- ---------------------------------------------------------------------
CREATE OR REPLACE FUNCTION public.current_company_ref()
 RETURNS text
 LANGUAGE sql
 STABLE SECURITY DEFINER
 SET search_path TO ''
AS $function$
  select c.subdomain
  from public.companies c
  where c.id = public.current_company_id()
$function$;

-- ---------------------------------------------------------------------
-- Papel na empresa atual. profiles_role_check aceita apenas
-- 'admin' e 'collaborator'. NÃO existe 'super' em public.profiles.
-- ---------------------------------------------------------------------
CREATE OR REPLACE FUNCTION public.current_company_role()
 RETURNS text
 LANGUAGE sql
 STABLE SECURITY DEFINER
 SET search_path TO ''
AS $function$
  with links as (
    select distinct p.company_id, p.role
    from public.profiles p
    join public.companies c on c.id = p.company_id
    where p.auth_user_id = auth.uid()
      and p.status = 'active'
      and p.company_id is not null
      and c.status in ('active','trial')
  )
  select case when count(*) = 1 then (array_agg(role))[1] else null end from links
$function$;

-- ---------------------------------------------------------------------
-- Subdomínio da empresa atual (helper usado pelas policies de Storage).
-- ---------------------------------------------------------------------
CREATE OR REPLACE FUNCTION public.current_company_subdomain()
 RETURNS text
 LANGUAGE sql
 STABLE SECURITY DEFINER
 SET search_path TO ''
AS $function$
  select lower(c.subdomain)
  from public.companies c
  where c.id = public.current_company_id()
$function$;

-- ---------------------------------------------------------------------
-- Ref do colaborador derivada do vínculo (nunca do corpo da chamada).
-- ---------------------------------------------------------------------
CREATE OR REPLACE FUNCTION public.current_collaborator_ref()
 RETURNS text
 LANGUAGE sql
 STABLE SECURITY DEFINER
 SET search_path TO ''
AS $function$
  select p.collaborator_ref
  from public.profiles p
  where p.auth_user_id = auth.uid()
    and p.company_id = public.current_company_id()
    and p.status = 'active'
  limit 1
$function$;

-- ---------------------------------------------------------------------
-- Comparações usadas pelas policies de tenant.
-- ---------------------------------------------------------------------
CREATE OR REPLACE FUNCTION public.is_current_company_ref(p_ref text)
 RETURNS boolean
 LANGUAGE sql
 STABLE SECURITY DEFINER
 SET search_path TO ''
AS $function$
  select exists (
    select 1
    from public.companies c
    where c.id = public.current_company_id()
      and c.subdomain = p_ref
  )
$function$;

CREATE OR REPLACE FUNCTION public.is_current_company_name(p_name text)
 RETURNS boolean
 LANGUAGE sql
 STABLE SECURITY DEFINER
 SET search_path TO ''
AS $function$
  select exists (
    select 1
    from public.companies c
    where c.id = public.current_company_id()
      and c.name = p_name
  )
$function$;

CREATE OR REPLACE FUNCTION public.is_company_member(p_company uuid)
 RETURNS boolean
 LANGUAGE sql
 STABLE SECURITY DEFINER
 SET search_path TO ''
AS $function$
  select p_company is not null and p_company = public.current_company_id()
$function$;

CREATE OR REPLACE FUNCTION public.is_company_admin(p_company uuid)
 RETURNS boolean
 LANGUAGE sql
 STABLE SECURITY DEFINER
 SET search_path TO ''
AS $function$
  select p_company is not null
     and p_company = public.current_company_id()
     and public.current_company_role() = 'admin'
$function$;

-- ---------------------------------------------------------------------
-- Super usuário global: só ações globais (platform-admin / caepi-base).
-- NUNCA concede contexto de empresa. Deriva de auth.uid().
-- ---------------------------------------------------------------------
CREATE OR REPLACE FUNCTION public.is_platform_admin()
 RETURNS boolean
 LANGUAGE sql
 STABLE SECURITY DEFINER
 SET search_path TO ''
AS $function$
  select exists (
    select 1 from public.platform_admins pa
    where pa.auth_user_id = auth.uid() and pa.status = 'active'
  )
$function$;

/**
 * Atestados médicos.
 *
 * Regras do fluxo (Entrega 1):
 *  1. O arquivo é enviado ao Storage ANTES de qualquer INSERT.
 *  2. Depois do upload, o app CONFIRMA no servidor que o objeto existe naquele
 *     bucket e que o tamanho gravado corresponde ao arquivo escolhido.
 *  3. Só então o registro é inserido. Se upload ou confirmação falharem,
 *     NENHUM registro é criado — o usuário vê o erro e tenta de novo.
 *  4. O servidor ainda valida a finalização em gatilho: caminho não vazio,
 *     objeto existente, pasta da empresa do registro e pasta do próprio
 *     colaborador. Chamada direta à API passa pela mesma validação.
 *  5. O registro finalizado é imutável no banco. Correção = NOVA VERSÃO
 *     (`replaces_id`), que preserva o original e o arquivo original.
 *  6. Registros antigos sem arquivo NÃO são apagados nem reatribuídos: eles
 *     continuam listados e sinalizados como "sem arquivo", com a opção de
 *     receber uma nova versão com o documento.
 *
 * Compatibilidade: o select tenta as colunas de versionamento e, se o banco
 * ainda não tiver a migração aplicada, cai automaticamente para a leitura
 * antiga (nesse caso a correção por versão fica indisponível na UI).
 */

const listeners = new Set<() => void>();

function emit(): void {
  listeners.forEach((listener) => listener());

function derive(certificates: MedicalCertificate[]): MedicalCertificate[] {
  const childOf = new Map<string, string>();
  certificates.forEach((cert) => {
    if (cert.replacesId) childOf.set(cert.replacesId, cert.id);
  });
  certificates.forEach((cert) => {
    cert.supersededBy = childOf.get(cert.id) ?? null;
    cert.isCurrent = cert.supersededBy === null;
  });
  return certificates.filter((cert) => cert.isCurrent);
}

function setState(patch: Partial<MedicalCertificateState>): void {
  const next = { ...state, ...patch };
  if (patch.certificates) {
    next.current = derive(patch.certificates);
  }
  state = next;
  emit();
}

function mapRow(r: Record<string, unknown>): MedicalCertificate {
  const storagePath = (r.storage_path as string) || undefined;
  const previewDataUrl = (r.preview_data_url as string) || "";
  return {

    collaboratorId: (r.collaborator_ref as string) ?? "",
    collaboratorName: (r.collaborator_name as string) ?? "",
    establishment: (r.establishment as string) ?? "",

  if (!error) return false;
  if (error.code === "42703" || error.code === "PGRST204") return true;

async function resolveCompanyId(ref: string): Promise<string> {
  if (!ref) throw new Error("company not resolved");
  const { data, error } = await supabase.from("companies").select("id").eq("subdomain", ref).maybeSingle();
  if (error) throw new Error(error.message);
  if (!data) throw new Error("company not resolved");
  return String(data.id);
}

async function ensureCompanyId(): Promise<string> {
  if (state.companyId) return state.companyId;
  const companyId = await resolveCompanyId(companyRef);
  setState({ companyId });
  return companyId;
}

async function refresh(): Promise<void> {
  try {
    const companyId = state.companyId || (await resolveCompanyId(companyRef));

    let versioningSupported = true;
    let { data, error } = await supabase
      .from("medical_certificates")
      .select(VERSION_COLUMNS)
      .eq("company_ref", companyRef)
      .order("created_at", { ascending: false });

    if (isMissingColumnError(error)) {
      versioningSupported = false;
      ({ data, error } = await supabase
        .from("medical_certificates")
        .select(BASE_COLUMNS)
        .eq("company_ref", companyRef)
        .order("created_at", { ascending: false }));
    }

    if (error) throw error;

    setState({
      certificates: (data ?? []).map((r) => mapRow(r as Record<string, unknown>)),
      companyId,
      versioningSupported,
      loaded: true,
      loading: false,
      error: null,
    });
  } catch {
    setState({
      loaded: true,
      loading: false,
      error: "Não foi possível carregar os atestados médicos.",
    });
  }
}

export async function loadMedicalCertificates(): Promise<void> {
  if (state.loading) return;
  setState({ loading: true });
  await refresh();
}

function sanitizeStorageName(name: string): string {
  return (
    name
      .toLowerCase()
      .normalize("NFD")
      .replace(/[^a-z0-9.]+/g, "-")
      .replace(/(^-|-$)/g, "")
      .slice(0, 60) || "atestado"
  );
}

interface UploadResult {
  ok: boolean;
  path?: string;
  error?: string;
}

/**
 * Confirma, no servidor, que o objeto existe no bucket e que o tamanho
 * gravado corresponde ao arquivo escolhido. Não cria registro nenhum.
 *
 * A leitura da própria pasta de atestados é autorizada pela policy mesmo antes
 * de o registro existir (storage_path_is_own_certificate_folder).
 */
async function confirmUploadedObject(
  path: string,
  expectedSize: number
): Promise<{ ok: boolean; error?: string }> {
  try {
    const slash = path.lastIndexOf("/");
    const folder = slash >= 0 ? path.slice(0, slash) : "";
    const fileName = slash >= 0 ? path.slice(slash + 1) : path;

    const { data, error } = await supabase.storage
      .from(BUCKET)
      .list(folder, { search: fileName, limit: 100 });

    if (error) {
      return {
        ok: false,
        error: "Não foi possível confirmar o envio do arquivo. Nada foi cadastrado — tente novamente.",
      };
    }

    const found = (data ?? []).find((item) => item.name === fileName);
    if (!found) {
      return {
        ok: false,
        error: "O envio do arquivo não foi confirmado no servidor. Nada foi cadastrado — tente novamente.",
      };
    }

    const storedSize = Number((found.metadata as { size?: number } | null)?.size ?? NaN);
    if (Number.isFinite(storedSize) && expectedSize > 0 && storedSize !== expectedSize) {
      return {
        ok: false,
        error: "O arquivo gravado não corresponde ao enviado. Nada foi cadastrado — tente novamente.",
      };
    }

    return { ok: true };
  } catch {
    return {
      ok: false,
      error: "Não foi possível confirmar o envio do arquivo. Nada foi cadastrado — tente novamente.",
    };
  }
}

/**
 * Etapa 1 do envio: grava o arquivo no Storage privado, CONFIRMA a gravação
 * (existência + tamanho) e só então devolve o caminho. Nenhum registro de
 * banco é criado aqui.
 */
async function uploadCertificateFile(file: File, collaboratorId: string): Promise<UploadResult> {
  const path = `${companyRef}/atestados/${collaboratorId}/${Date.now()}-${sanitizeStorageName(file.name)}`;
  try {
    const { data, error } = await supabase.storage.from(BUCKET).upload(path, file, {
      upsert: false,
      contentType: file.type || undefined,
    });

    if (error) {
      return {
        ok: false,
        error: "Não foi possível enviar a imagem do atestado. Verifique a conexão e tente novamente.",
      };
    }

    if (!data?.path) {
      return {
        ok: false,
        error: "O envio da imagem não foi confirmado. Nada foi cadastrado — tente novamente.",
      };
    }

    const confirmation = await confirmUploadedObject(data.path, file.size);
    if (!confirmation.ok) {
      // Objeto enviado mas não confirmado: inalcançável (fechado). Remoção
      // best-effort, nunca pré-requisito.
      void supabase.storage
        .from(BUCKET)
        .remove([data.path])
        .then(
          () => undefined,
          () => undefined
        );
      return { ok: false, error: confirmation.error };
    }

    return { ok: true, path: data.path };
  } catch {
    return {
      ok: false,
      error: "Não foi possível enviar a imagem do atestado. Verifique a conexão e tente novamente.",
    };
  }
}

function describeInsertError(error: { code?: string; message?: string } | null): string {
  const code = error?.code ?? "";
  const message = error?.message ?? "";

  if (code === "42703" || code === "PGRST204" || isMissingColumnError(error)) {
    return "A correção por nova versão ainda não está habilitada no banco. Nada foi cadastrado.";
  }
  if (
    /arquivo não existe|não pertence à pasta da empresa|pasta de outro colaborador|já pertence a um atestado|já usado por documento|referência não é um caminho|empresa do registro não existe|não corresponde ao company_id|sem empresa identificada|caminho de atestado incompleto|precisa estar em/i.test(
      message
    )
  ) {
    return "O servidor recusou a finalização: o arquivo não é um objeto válido e autorizado desta empresa e deste colaborador. Nada foi cadastrado — envie novamente pelo sistema.";
  }
  if (
    code === "23505" ||
    code === "23514" ||
    /medical_certificates_(replaces_id|storage_path)_uidx|requires_file/.test(message)
  ) {
    return "Este envio não pôde ser finalizado (versão ou arquivo em conflito). Nada foi cadastrado — tente novamente.";
  }
  if (code === "42501" || /row-level security|policy/i.test(message)) {
    return "Sem permissão para cadastrar o atestado neste momento. Nada foi cadastrado.";
  }
  return "Não foi possível cadastrar o atestado. Nada foi cadastrado — tente novamente.";
}

/**
 * Registra um atestado médico em etapas explícitas:
 *   1) upload e confirmação do arquivo no servidor;
 *   2) INSERT do registro (somente se o arquivo foi confirmado).
 *
 * Em qualquer falha o retorno traz `retryable: true` e nada é persistido
 * como "envio concluído".
 */
export async function addMedicalCertificate(input: NewMedicalCertificate): Promise<MedicalCertificateResult> {
  if (!input.file) return { ok: false, error: "Anexe a foto do atestado médico.", retryable: true };
  if (!input.issuedOn) return { ok: false, error: "Informe a data do atestado.", retryable: true };
  if (!input.cid.trim()) return { ok: false, error: "Informe o CID do atestado.", retryable: true };
  if (input.replacesId && !state.versioningSupported) {
    return {
      ok: false,
      error: "A correção por nova versão ainda não está habilitada no banco.",
      retryable: false,
    };
  }

  try {
    const companyId = await ensureCompanyId();

    const upload = await uploadCertificateFile(input.file, input.collaboratorId);
    if (!upload.ok || !upload.path) {
      return { ok: false, error: upload.error ?? "Falha no envio do arquivo.", retryable: true };
    }

    const payload: Record<string, unknown> = {
      company_id: companyId,
      company_ref: companyRef,
      collaborator_ref: input.collaboratorId,
      collaborator_name: input.collaboratorName,
      area: input.area || null,
      establishment: input.establishment || null,
      certificate_type: input.certificateType,
      issued_on: input.issuedOn,
      leave_days: Math.max(0, Number(input.leaveDays) || 0),
      cid: input.cid.trim(),
      notes: input.notes.trim() || null,
      storage_path: upload.path,
      preview_data_url: null,
      file_name: input.file.name || null,
      created_by: input.createdBy || null,
    };
    if (input.replacesId) payload.replaces_id = input.replacesId;

    const { error } = await supabase.from("medical_certificates").insert(payload);

    if (error) {
      // O arquivo enviado não pode ser reaproveitado: sem registro, ele fica
      // inalcançável (fechado). A remoção depende de permissão de admin e é
      // best-effort — nunca é pré-requisito para continuar.
      void supabase.storage
        .from(BUCKET)
        .remove([upload.path])
        .then(
          () => undefined,
          () => undefined
        );
      return { ok: false, error: describeInsertError(error), retryable: true };
    }

    await refresh();
    return { ok: true };
  } catch {
    return {
      ok: false,
      error: "Não foi possível concluir o cadastro. Nada foi registrado — tente novamente.",
      retryable: true,
    };
  }
}

  -v storage_policy_ack="<HASH_DO_§5>" \

-- corpo integral de 20261101100200_..._up.sql
-- corpo integral de 20261101100300_..._up.sql
-- corpo integral de 20261101100400_..._up.sql

O SQL Editor envia o script inteiro em uma transação. Como os arquivos não têm

## 5. Inventário de `storage.objects` e hash (consulta corrigida)

A migration aborta **antes de qualquer `DROP`** enquanto o hash do conjunto de
policies desconhecidas não for informado — **inclusive quando o conjunto está
vazio** (`d41d8cd98f00b204e9800998ecf8427e`). Reconhecer "não há nada a
reconhecer" também é um ato explícito.

A consulta abaixo devolve **uma linha**, com o inventário completo, **um único
hash** calculado exatamente como a migration calcula (concatenação em ordem de
`policyname`, sem separador extra) e o hash da string vazia como referência.
**Não há `GROUP BY`** — o defeito anterior produzia um hash por policy.

```sql
with known(name) as (
  values ('documents_read'),('documents_insert'),('documents_update'),('documents_delete'),
         ('branding_read'),('branding_insert'),('branding_update'),('branding_delete'),
         ('caepi_base_all'),('caepi_base_platform_all')
), pol as (
  select
    p.policyname,
    p.cmd,
    array_to_string(p.roles::text[], ',')                        as roles,
    coalesce(nullif(btrim(p.qual), ''), '<null>')                as using_expr,
    coalesce(nullif(btrim(p.with_check), ''), '<null>')          as check_expr
  from pg_policies p
  where p.schemaname = 'storage'
    and p.tablename  = 'objects'
    and p.policyname not in (select name from known)
), agg as (
  select coalesce(string_agg(
           format(E'\n  - %s | cmd=%s | roles=%s | using=%s | check=%s',
                  policyname, cmd, roles, using_expr, check_expr),
           '' order by policyname), '') as inventory
  from pol
)
select
  inventory                                        as inventario_completo,
  md5(inventory)                                   as ack_hash,
  md5('')                                          as hash_da_string_vazia,
  (inventory = '')                                 as conjunto_vazio
from agg;
```

- `conjunto_vazio = true` → o valor válido de `ack_hash` é o da coluna
  `hash_da_string_vazia`.
- `conjunto_vazio = false` → revise **cada linha** de `inventario_completo`
  antes de usar `ack_hash`.

**O que isso NÃO é:** cobertura automática. Não existe verificação confiável de
"expressão permissiva" por texto — `bucket_id <> 'avatars'` passaria por
qualquer regex. Os bloqueios duros da migration cobrem apenas casos
verificáveis; o resto é revisão humana obrigatória. A única prova real de
isolamento é o roteiro do §12 executado com identidades distintas.

## 6. Propriedade de referências (item 1)

### 6.1 O problema

Antes, `storage_object_scope(p_name)` decidia o escopo olhando **apenas o
registro** (`documents.storage_path`, `medical_certificates.storage_path`,
`internal_regulations.storage_path`, `company_settings.logo_path`). Se o
cliente conseguisse inserir uma linha apontando para um arquivo de outra
empresa, essa linha passaria a ser "prova" de propriedade — e o helper
autorizaria acesso.

### 6.2 O que o servidor impõe agora

Toda escrita de referência passa por `storage_reference_problem(bucket, caminho,
company_id, company_ref, collaborator_ref, tipo)`, chamada por **quatro
gatilhos**:

| Tabela | Gatilho | Momentos |
|---|---|---|
| `documents` | `documents_validate_storage_reference` | INSERT e UPDATE de `storage_path`, `company_id`, `company_ref` |
| `medical_certificates` | `medical_certificates_validate_file_reference` | INSERT |
| `internal_regulations` | `internal_regulations_validate_storage_reference` | INSERT e UPDATE de `storage_path`, `company_ref` |
| `company_settings` | `company_settings_validate_branding_reference` | INSERT e UPDATE de `logo_path`, `letterhead_path`, `company_id` |

A validação recusa, nesta ordem:

1. caminho vazio, `data:`, `http(s):`, `blob:`, caminho absoluto ou com `..`;
2. bucket incompatível com o tipo (`branding` só no bucket `branding`; documento,
   atestado e regulamento só em `documents`);
3. `company_id` que não existe, ou `company_ref` que não corresponde ao
   `company_id` do registro, ou registro sem empresa identificada;
4. **prefixo do caminho diferente do subdomínio da empresa do registro** →
   arquivo de outra empresa é recusado;
5. **objeto inexistente** em `storage.objects` para aquele `(bucket_id, name)`;
6. atestado fora de `<empresa>/atestados/<colaborador>/`, com colaborador vazio
   ou apontando para a pasta de **outra pessoa**;
7. atestado apontando para caminho já usado por documento/regulamento, e
   documento/regulamento apontando para caminho de atestado;
8. branding fora de `<empresa>/logo/` ou `<empresa>/letterhead/`.

Consequência prática: **o registro criado pelo cliente deixa de ser prova de
propriedade**. Ele só é aceito se o objeto existir no bucket correto e se o
caminho pertencer, por prefixo, à empresa do próprio registro.

### 6.3 Helpers bucket-aware

| Antes | Agora |
|---|---|
| `storage_object_scope(p_name)` | `storage_object_scope(p_bucket, p_name)` |
| `storage_path_is_medical_certificate(p_name)` | `storage_path_is_medical_certificate(p_bucket, p_name)` |
| — | `storage_object_exists(p_bucket, p_name)` |
| — | `storage_reference_problem(...)` |

O mesmo `name` em buckets diferentes **não é o mesmo arquivo**
(`storage.objects` é único por `(bucket_id, name)`). `storage_object_scope` agora
retorna `null` quando o objeto não existe naquele bucket ou quando o caminho não
está na pasta da empresa atual.

### 6.5 Leitura da própria pasta de atestados

Para permitir o fluxo `upload → confirmação → INSERT`, a policy de leitura
autoriza o colaborador a listar/ler **a própria pasta** de atestados mesmo antes
de o registro existir (`storage_path_is_own_certificate_folder`). Isso não
amplia acesso a nada de outra pessoa ou de outra empresa.

### 6.6 Dependência de `BYPASSRLS` (verificada agora)

A checagem de existência lê `storage.objects`, cujo dono é
`supabase_storage_admin` — com `relrowsecurity = true` e
`relforcerowsecurity = false`. As funções são `SECURITY DEFINER`: se o dono
delas **não** tiver `BYPASSRLS`, as policies `to authenticated` escondem as
linhas e `storage_object_exists` devolveria `false` para tudo, negando o acesso
inteiro (fail-closed, mas inutilizável).

Verificado no banco atual: executor `postgres`, `rolbypassrls = true`,
`rolsuper = false`, dono de `storage.objects` = `supabase_storage_admin`.

O `$check$` da migration 3 **falha** se o dono de
`storage_reference_problem(...)` não tiver `BYPASSRLS`. Assim o problema aparece
na aplicação, não em produção.

## 7. Auditoria da escrita em `system_audit_logs` (item 4)

Consulta executada nesta rodada (leitura) e resultado:

| Item | Resultado |
|---|---|
| `relrowsecurity` | `true` |
| `relforcerowsecurity` | **`false`** |
| proprietário da tabela | `postgres` |
| policy aplicável | `system_audit_logs_all` — `ALL`, `to public`, `using false`, `with check false` |
| `GRANT` | `anon`/`authenticated`/`service_role`/`postgres` têm privilégios de tabela, mas a RLS nega todas as linhas |
| proprietário da função de auditoria | `postgres` (dono da sessão que aplica a migration) |

**Conclusão técnica:** `relforcerowsecurity` isoladamente **não** decide a
questão — o que decide é **quem executa** e **se a RLS se aplica a ele**. Como
`relforcerowsecurity = false`, o dono da tabela (`postgres`) **não** é submetido
à RLS; a função é `SECURITY DEFINER` com esse dono, então o `INSERT` da
auditoria funciona apesar da policy `false`.

Se `relforcerowsecurity` virar `true`, **ou** a função trocar de dono para um
papel sem privilégio, **todo cadastro de atestado passa a falhar** no
`after insert`. Reconferência:

```sql
-- RLS, FORCE RLS e proprietário das tabelas envolvidas
select c.relname, c.relrowsecurity, c.relforcerowsecurity,
       pg_get_userbyid(c.relowner) as owner
from pg_class c join pg_namespace n on n.oid = c.relnamespace
where n.nspname = 'public'
  and c.relname in ('system_audit_logs','medical_certificates','documents');

-- dono e SECURITY DEFINER das funções de auditoria/gatilho
select p.proname, pg_get_userbyid(p.proowner) as owner, p.prosecdef
from pg_proc p join pg_namespace n on n.oid = p.pronamespace
where n.nspname = 'public'
  and p.proname in ('medical_certificates_audit_insert',
                    'medical_certificates_validate_file_reference',
                    'documents_validate_storage_reference');

-- privilégios efetivos do dono da função sobre a tabela de auditoria
select has_table_privilege('postgres', 'public.system_audit_logs', 'INSERT') as pode_insert;
```

**Não desligue RLS para contornar.** Se divergir do esperado, pare e reporte.

## 8. Inventário de `documents` (item 2)

Estado real conferido (`pg_policies`):

| Policy | cmd | papéis | expressão |
|---|---|---|---|
| `documents_all` | ALL | `public` | `false` / `false` |
| `legacy_all_disabled` | ALL | `authenticated` | `false` / `false` |
| `tenant_read` | SELECT | `authenticated` | `is_current_company_ref(company_ref)` (substituída) |
| `tenant_write` | ALL | `authenticated` | `is_current_company_ref(company_ref) AND current_company_role() = 'admin'` |

**Defeito corrigido:** a versão anterior abortava com qualquer policy
`SELECT`/`ALL` cujo `qual` não fosse literalmente `false` — inclusive
`tenant_write`, que é a autorização administrativa necessária.

**Regra atual:**

- `tenant_write` é verificada **pela forma**: `PERMISSIVE`, `cmd = ALL`, papéis
  `{authenticated}`, expressão com `is_current_company_ref` **e**
  `current_company_role() = 'admin'`, sem `'super'` e sem `true`. Se mudar,
  aborta com a expressão real impressa.
- Policies **RESTRITIVAS** nunca são tratadas como concessão: restritiva só
  estreita; não soma por OR.
- Policy desconhecida só bloqueia se for **PERMISSIVA** e de leitura
  (`SELECT`/`ALL`) com `qual` diferente de `false`.
- Policy desconhecida de **escrita** não amplia leitura: gera aviso
  (`raise notice`), não bloqueio. As referências de arquivo são validadas por
  gatilho de qualquer forma.

A conferência final aplica exatamente as mesmas regras — não há divergência
entre inventário e verificação.

## 9. Atestados: fluxo recuperável e finalização validada (item 3)

### 9.1 Fluxo (3 etapas)

1. **Upload** para `documents/<subdominio>/atestados/<ref>/...` com `upsert: false`.
2. **Confirmação no servidor**: o app lista a própria pasta e compara o tamanho
   gravado com o arquivo escolhido. Sem confirmação, **nada é cadastrado**.
3. **INSERT**: só então o registro é criado. Se o INSERT falhar, não há registro;
   o objeto é removido por best-effort e o usuário tenta de novo.

### 9.2 Recusas do servidor na finalização

- caminho vazio → recusado pelo gatilho **e** pela constraint
  `medical_certificates_requires_file`;
- arquivo inexistente no bucket → recusado;
- caminho de outra empresa (prefixo diferente) → recusado;
- caminho na pasta de **outro colaborador** → recusado;
- caminho já usado por documento/regulamento → recusado;
- `replaces_id` de outra empresa/colaborador, versão já substituída ou arquivo
  reaproveitado → recusado (gatilho de revisão);
- chamada direta ao PostgREST → passa pelos **mesmos** gatilhos.

### 9.3 Concorrência

- `pg_advisory_xact_lock(hashtext('medical_certificates:revision:' || replaces_id))`
  serializa revisões simultâneas do mesmo original;
- índice único parcial em `replaces_id` faz a segunda transação falhar com
  `duplicate key` (é a proteção esperada, não um bug);
- índice único em `storage_path` impede dois registros com o mesmo caminho.

### 9.4 Limite honesto sobre "arquivo novo"

O índice único em `storage_path` **não** impede, sozinho, que o conteúdo do
objeto seja sobrescrito no Storage. Quem impede isso é a policy:
`storage_can_update` nega UPDATE em caminho de atestado e `storage_can_insert`
nega gravar em caminho já registrado como atestado. O app também usa
`upsert: false`. Testes de "alteração do objeto durante a finalização" estão no
§12.3 — e são testes de **comportamento**, não uma prova formal.

### 9.5 Registros existentes sem arquivo

Não são apagados, não são reatribuídos, não são "corrigidos por suposição".
Aparecem em `medical_certificates_without_file` e, na UI, com o selo
**“Sem arquivo”** e o botão **“Anexar arquivo”**, que cria uma nova versão.
Estado atual confirmado: `medical_certificates` **vazia** (0 linhas).

### 9.6 Correção legítima

Correção = **nova versão** (`replaces_id` + `revision`), com indicação da versão
vigente na interface. **Não** existe rotina de desabilitar gatilho.

## 10. Subdomínio e helpers

### 10.1 `app.allow_subdomain_change` não é autorização

É um GUC: qualquer sessão define o próprio. O gatilho exige, em conjunto:

1. `public.is_platform_admin()` (derivado de `auth.uid()` + `platform_admins.status='active'`),
   **ou** `current_user in ('postgres','supabase_admin')` — caminho que só existe
   no console SQL (o PostgREST executa como `authenticator` → `anon`/`authenticated`/`service_role`);
2. o marcador `app.allow_subdomain_change = 'true'`.

A função é `SECURITY INVOKER` de propósito: com `DEFINER`, `current_user` viraria
o dono e o teste de proprietário seria sempre verdadeiro. O `$check$` falha se
alguém a tornar `DEFINER` ou se ela ficar executável por `anon`/`authenticated`.

### 10.2 Papel "super"

| Fato verificado | Resultado |
|---|---|
| `profiles_role_check` | `CHECK (role = ANY (ARRAY['admin','collaborator']))` |
| `profiles.role` default | `'collaborator'` |
| Onde 'super' existe no **frontend** | só como rótulo de rota |
| Onde 'super' existe no **banco** | **9 policies legadas** (ver abaixo), sempre como `current_company_role() = ANY (ARRAY['admin','super'])` |

Não existe acesso global a dados de tenant por string de papel: como
`profiles.role` nunca assume `'super'`, esse ramo é **código morto** — não
concede nada a ninguém. O super usuário global (`platform_admins`) só atua em
`caepi-base`/`platform-admin`. Nenhuma regra SQL **do pacote** usa `'super'`.

**Correção de documentação (achado desta rodada, leitura de `pg_policies`):**
a versão anterior do README dizia que `'super'` existia *apenas* no frontend.
Isso está errado. As policies abaixo, já existentes no banco, citam `'super'`:

| Tabela | Policies | Papéis |
|---|---|---|
| `medical_certificates` | `medical_certificates_insert`, `medical_certificates_read` | `authenticated` |
| `medical_certificate_followups` | `_insert`, `_read`, `_update` | **`public`** |
| `apr_records` | `apr_records_collaborator_insert`, `apr_records_collaborator_update` | (legado) |
| `mood_followups` | `mood_followups_update`, `mood_followups_write` | (legado) |

Impacto: nenhum privilégio extra (ramo inalcançável), **mas** as três policies
de `medical_certificate_followups` são `to public` — concedidas também a `anon`.
Na prática `anon` é negado porque `is_current_company_ref()` depende de
`auth.uid()` e devolve `null`. Ainda assim é configuração frouxa.

Essas policies **não** são alteradas por este pacote (fora de escopo declarado).
Ficam registradas para a próxima entrega: recomendar `to authenticated` no lugar
de `to public` e remover o ramo `'super'` morto, revisando cada tabela.

### 10.3 Múltiplos vínculos → acesso fechado (decisão mantida)

`current_company_id()` devolve `null` com mais de um vínculo ativo
(`count(*) = 1`). Com isso role/subdomain/collaborator_ref ficam `null` e todas
as policies negam. Fail-closed deliberado; a seleção de empresa é outra entrega.

### 10.4 Privilégios `EXECUTE` dos helpers — corrigido no arquivo 3 (item 5)

**Achado real** (`pg_proc.proacl`, leitura no ambiente atual):

| Função | ACL observada | Leitura |
|---|---|---|
| `current_collaborator_ref()` | `=X/postgres \| postgres=X \| anon=X \| authenticated=X \| service_role=X` | **PUBLIC** (`=X/...`) **e** `anon` explícito |
| `current_company_subdomain()` | `postgres=X \| anon=X \| authenticated=X \| service_role=X` | `anon` explícito |
| `current_company_id()`, `current_company_role()`, `is_current_company_ref`, `is_company_member`, `is_company_admin`, `is_platform_admin` | sem `anon`, sem PUBLIC | corretos |

**Por que revogar só de `anon` não basta:** o item `=X/postgres` é o grant
implícito a `PUBLIC`. Ele é herdado por **todo** papel — inclusive `anon` e
qualquer papel criado depois. Remover apenas o grant direto de `anon` mantém o
acesso por `PUBLIC` de pé, e o `anon` continua executando.

**Correção aplicada no pacote** (seção 2.1 de
`20261101100300_..._storage_tenant_isolation_up.sql`):

```sql
revoke all on function public.current_collaborator_ref()  from public;
revoke all on function public.current_collaborator_ref()  from anon;
grant  execute on function public.current_collaborator_ref() to authenticated;
-- idem para current_company_subdomain(), current_company_id(),
-- current_company_role(), is_current_company_ref(text),
-- is_company_member(uuid), is_company_admin(uuid)
```

**Chamadas legítimas preservadas:** policies `to authenticated`; funções
`SECURITY DEFINER` com dono `postgres` (o dono sempre executa); `service_role`
(grant explícito, não afetado por `revoke ... from public`). **Nada legítimo é
executado por `anon`.** O `$check$` da migration 3 falha se o direito a
`PUBLIC`/`anon` voltar ou se `authenticated` perder o acesso. A recuperação
(§13) **não reabre** `PUBLIC`/`anon` de propósito — só verifica que
`authenticated` continua com `EXECUTE`.

**Consulta de conferência (após aplicar):**

```sql
select p.oid::regprocedure::text as assinatura,
       coalesce(array_to_string(p.proacl, ' | '), '<NULL: PUBLIC EXECUTE>') as acl,
       has_function_privilege('anon', p.oid, 'EXECUTE')          as anon_exec,
       has_function_privilege('authenticated', p.oid, 'EXECUTE') as auth_exec
from pg_proc p join pg_namespace n on n.oid = p.pronamespace
where n.nspname = 'public'
  and p.proname in ('current_company_id','current_company_role','current_collaborator_ref',
                    'current_company_subdomain','is_current_company_ref',
                    'is_company_member','is_company_admin')
order by p.proname;
```

Esperado depois do pacote: `anon_exec = false` em **todas**, `auth_exec = true`
em **todas**, e nenhuma ACL contendo `=X/` (grant a PUBLIC).

§F. MANIFESTO DE INTEGRIDADE (SHA-256) — COMO É PRODUZIDO
=======================================================================

ATENÇÃO, LIMITE DECLARADO: esta sessão não tem acesso a shell. Portanto eu
NÃO calculei SHA-256 e NÃO afirmei que os blocos coincidem byte a byte. O
que existe é o verificador que faz exatamente isso, de forma reprodutível,
e que FALHA (exit != 0) em qualquer divergência.

Arquivo: docs/entrega1/verify_package.py
Saída:   docs/entrega1/MANIFESTO_INTEGRIDADE.txt

Uso (na raiz do repositório):
  python3 docs/entrega1/verify_package.py

O que ele faz, por bloco:
  1. extrai do TXT o conteúdo entre "===== FILE: caminho =====" e o próximo
     marcador;
  2. remove apenas o separador final (uma linha em branco antes do próximo
     marcador) — regra explícita, aplicada igual para todos;
  3. compara byte a byte com o arquivo original do repositório;
  4. grava no manifesto: caminho | bytes original | sha256 original |
     bytes extraído | sha256 extraído | OK/DIVERGENTE;
  5. termina com código 1 se qualquer bloco divergir, se faltar marcador ou
     se algum dos 17 arquivos não existir.

O manifesto entregue neste pacote NÃO contém hashes inventados. Enquanto o
verificador não rodar, o estado honesto é: "17 blocos presentes; integridade
ainda não comprovada por execução". Rode o comando acima e o manifesto será
preenchido com os hashes reais.
